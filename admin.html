iMaqomAdmin

Qanday ishlaydi

  1. Bu sahifada maqom, dars, test va sozlamalarni tahrirlaysiz. O'zgarishlar shu brauzerda qoralama sifatida saqlanadi.
  2. Tugatgach data.json yuklab olish tugmasini bosing.
  3. Yuklangan data.json faylini GitHub'dagi ilova papkasidagi eski data.json o'rniga qo'ying (Upload files).
  4. Bir-ikki daqiqadan keyin ilova yangilanadi. Foydalanuvchilar ilovani qayta ochganda yangi kontentni ko'radi.
Bu server bo'lmagan oddiy variant. Shu sabab foydalanuvchilar ro'yxati, token balansi, to'lovlar va statistika bu yerda yo'q. Ular uchun keyinroq server (masalan Supabase yoki Firebase) ulanadi.
Kimdir admin.html sahifasini ochsa ham, ilovani o'zgartira olmaydi: jonli ilova faqat siz GitHub'ga yuklagan data.json bilan o'zgaradi. Baribir, admin.html havolasini ochiq tarqatmang.
